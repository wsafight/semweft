# P0 实现与验收对照

本清单对应 [features.md](features.md) 的 v0.1 交付表及 A–E 的 P0 条目。功能已实现；Rust 和 Go 的能力状态仍为 experimental。单元测试、临时仓库集成测试与真实 rust-analyzer 回归验证的是实现行为，不代表已通过真实仓库质量、任务效果或规模性能的正式门槛。

## 可重复验证

```bash
cargo fmt --all -- --check
cargo clippy --locked --workspace --all-targets --all-features -- -D warnings
cargo test --locked --workspace
cargo test --locked --workspace --all-features

# 已安装 rust-analyzer 和 rust-src；仅授权测试生成的临时工作区
cargo test --locked -p semweft-cli --all-features --test cli \
  lsp_refresh_matches_cold_with_annotated_targets -- --ignored --nocapture
cargo test --locked -p semweft-cli --all-features --test mvp \
  trusted_daemon_publishes_l3_and_refreshes_references -- --ignored --nocapture
```

CI 在 Linux、macOS、Windows 上检查默认与全部 feature；依赖真实 rust-analyzer 的两项回归在专门任务运行。Go 生产流程通过受控 SCIP 生产器验证发布、失败重试和授权撤销，尚未以真实 scip-go 项目完成语言质量验收。

## 仍需独立验收的质量门槛

功能完成不改变 [roadmap.md](roadmap.md) 与 [quality.md](quality.md) 的验收要求。Rust 至少 3 个真实仓库、20 个独立标注改动任务、至少 2 个仓库的纯 CLI 人工对照、真实符号/影响质量、规模性能和 P95 500ms 语法可查目标，均需单独登记数据并测量。本次回归不能替代这些实验，尚不把 Rust 或 Go 标为正式支持。

已知分析边界仍显式进入响应：L1 仅名称候选；宏、生成物、条件编译的穷尽性、外部消费者和运行时分派不保证覆盖；Go 实验仅依赖深度 0。Git base 没有可匹配的保留语义索引时降级 L1。持久化目前保留所有已发布视图，生产存储与回收策略仍待负载测量。
